# End-to-end tests

End-to-end tests use the FFI crate and an in-memory remote storage backend to check sync correctness.

## Media integrity tests

Media integrity tests use only media-creation operations. Every file is named with a UUID and contains that UUID's `u128` encoded as 16 little-endian bytes. Every media read must return exactly those bytes.

<h3>Compaction integrity</h3>
<p>Setup: one device, one remote.</p>
<p className="e2e-test-card__description">Confirms that repeated compaction preserves the complete, unique operation history for the original and a fresh client.</p>

<div className="e2e-test-card__section">
<div className="e2e-test-card__label">Description</div>
<ol>
<li>Use metadata-only album-creation operations.</li>
<li>Run 64 deterministic rounds, creating 1–30 operations and pushing them through FFI in each round.</li>
<li>Allow repeated pushes to trigger remote compaction.</li>
<li>Fetch the compacted remote with a fresh FFI client.</li>
<li>Verify both clients contain every created operation and no duplicate dots.</li>
</ol>
</div>

Run FFI end-to-end tests with:

```sh
cargo nextest run --release -p lasco-ffi
```
