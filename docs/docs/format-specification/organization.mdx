# Source File Organization


## Project organization

| Component | Language | Status | Description |
|---|---|---|---|
| `lasco-core` | Rust | Active | Core library |
| `lasco-cli` | Rust | Not up to date | Command-line client |
| `lasco-swift` | Swift | Active | Native macOS and iOS client |

All clients call into `lasco-core` directly and share the same encrypted storage format and sync protocol.

---
