# Who We Are

<div style={{fontSize: '1.25rem', lineHeight: '1.7'}}>

Hey, I'm Pierre 👋

I'm building Lasco because I couldn't find software that pushes a photo library to generic file servers.

The plan is to monetize app development by providing our own hosting, easier to set up, with extra sharing features that are impossible to implement with regular file servers.

We want to prevent a single point of failure, so we will always support pushing to your own file servers.

The company is based in France, and we will provide Europe-based hosting.

</div>
